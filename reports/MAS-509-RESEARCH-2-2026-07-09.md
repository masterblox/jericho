## 2. Microsoft Flint — Agent Visualization Language

Repo: https://github.com/microsoft/flint-chart
Stars: 796 | Language: TypeScript | License: MIT | Created: 2026-05-13
Topics: ai-agents, charting-library, data-visualization, mcp-server

### What It Is
Flint is a visualization intermediate language that lets AI agents create expressive, polished visualizations from simple, human-editable chart specs. Instead of asking agents to tune verbose chart config (scales, axes, spacing, labels, layout), the Flint compiler derives optimized chart settings from data, semantic types, chart type, and encodings.

### Components
- `flint-chart` (npm): JavaScript/TypeScript library that compiles Flint input into Vega-Lite, ECharts, or Chart.js specs
- `flint-chart-mcp` (npm): MCP server that lets agents create, validate, and render charts from chat/coding environments

### Key Features
- 70+ semantic types (Rank, Temperature, Price, Country, etc.)
- Automatic layout adapts sizing, spacing, labels, marks, legends to data cardinality
- 30+ chart types across 3 backends (Vega-Lite, ECharts, Chart.js)
- MCP server gives agents chart tools and guidance
- Compact specs — agents produce small, human-editable chart definitions

### Fleet Relevance
- Iris (design agent) could use Flint via MCP for chart generation in reports
- DEV could use it for dashboard/report visualizations in Mechanica products
- The MCP server means any Hermes agent with MCP access could generate charts
- 796 stars in ~2 months suggests strong community traction

## 3. SkillCenter Paper

Title: "SkillCenter: A Large-Scale Source-Grounded Skill Library for Autonomous AI Agents"
Paper: https://arxiv.org/abs/2607.07676 (July 8, 2026)
Authors: Tianming Sha, Yue Zhao, Lichao Sun, Yushun Dong
Code: https://github.com/LabRAI/SkillCenter
Data: https://huggingface.co/datasets/Tommysha/skillcenter-bundles

### What It Is
The largest open skill library for AI agents by total count: 216,938 structured skills across 24 domain bundles. Pipeline produces 114,565 source-grounded skills from peer-reviewed journals, arXiv, and 24,000+ technical sources, plus 102,373 community skills from GitHub and ClawHub marketplace.

### Key Mechanics
- Multi-source acquisition pipeline
- SkillGate — LLM-based quality gate filtering
- Template-driven generation with iterative source-grounding
- Source grounding = each claim maps to exact quotation in source
- All skills ship as offline-searchable SQLite FTS5 bundles

### Fleet Relevance
- HIGH: 216K structured skills could supplement fleet agent knowledge
- HIGH: The source-grounding approach (traceability to exact quotes) mirrors what Carlos wants from his agents
- MEDIUM: Could integrate with Hermes skill system — SkillCenter skills as importable fleet resources
- LOW: 44-page paper — full integration would require dedicated engineering effort
- ACTION: Consider having DEV analyze the SQLite bundle format for potential Hermes skill import

## 4. TokenDiet — LLM Cost Optimization

Two separate projects share the "token diet" name:

### A. TokenDiet — Claude Code Plugin (tokendiet.dev)
Repo: https://github.com/Fortytude/TokenDiet (5 stars, created 2026-07-07)
Type: Claude Code / Codex / Copilot / Cursor plugin

Audits repo code for wasteful LLM API spend patterns:
- Missing prompt caching (cached reads are ~10% of input rate)
- Timestamp busting cache prefixes
- Uncapped retries
- Prompt bloat / redundant content
- Overpowered models for simple classify tasks
- Sync API on offline workloads (Batch API is 50% off)
- Missing max_tokens cap
- No cost/usage instrumentation

Key design principle: Never invents a dollar figure. Only cites published rates, never multiplies into fake totals.

### B. token-diet — Python CLI (PyPI v0.1.0)
Type: Prompt compression tool

Compresses prompts to use fewer tokens without losing meaning. Works offline (rule-based) or with Claude API (intelligent compression). Three levels: gentle, balanced, aggressive. Example from docs: 847 tokens → 234 tokens (72.4% reduction).

### Fleet Relevance
- HIGH: The Claude Code plugin could audit our fleet's LLM call patterns for waste
- MEDIUM: The Python CLI could compress fleet agent prompts before dispatch
- NOTE: The "31% cost savings" figure claimed in the task description was not found in either project's public documentation. Actual savings depend on call volume and existing optimization level. The plugin's design philosophy explicitly avoids fabricated dollar figures.
