# MediaPipe gesture assets

- `wasm/` is copied from `@mediapipe/tasks-vision` 0.10.35 (Apache-2.0).
- `models/gesture_recognizer.task` is Google MediaPipe Gesture Recognizer float16 revision 1, downloaded from the canonical Google-hosted model path used by MediaPipe.
- Model SHA-256: `97952348cf6a6a4915c2ea1496b4b37ebabc50cbbf80571435643c455f2b0482`.

These pinned files are served from Jericho's loopback origin so camera frames and gesture inference need no CDN or model request.
