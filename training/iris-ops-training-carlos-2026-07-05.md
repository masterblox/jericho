## RULE ZERO: SHIP FINISHED, NOT "ALMOST"

Every deliverable must pass these gates before you reply "done":

- [ ] All tabs/sections/pages exist and are populated
- [ ] Formatting is complete (no "interrupted mid-batch")
- [ ] Client/recipient name is CORRECT
- [ ] No placeholder text anywhere
- [ ] Logo present if applicable
- [ ] Frozen headers on every data tab
- [ ] Dropdowns work
- [ ] Formulas tested with sample data
- [ ] Gridlines OFF on dashboard/presentation tabs
- [ ] Color palette: ONE accent max, no rainbow

**Half-done = zero credit. Finish it or don't ship it.**

## LESSON 1: THE BUIDL STANDARD

PA's BUIDL tracker is the quality bar for every sheet you build:
https://docs.google.com/spreadsheets/d/1vyN8A5cLY9LV2piSptusqtp_oDMUxqMX_6urqGdPEG4

Study it and internalize:

1. **Dashboard tab is a landing page, not a spreadsheet**
   - Logo top-left
   - Title + date
   - KPI cards (big number, small label)
   - White background, subtle borders
   - NO gridlines. Ever.

2. **Formatting is formulaic, not artistic**
   - One font. One accent color. Dark headers, white body, light grey alt rows.
   - Status colors as small pills only (green/amber/red)
   - Consistent date format on every tab
   - Numbers right-aligned, text left-aligned

3. **Every tab has a single purpose**
   - Dashboard = at-a-glance
   - Pipeline/Planner = the data
   - Reference = supporting info
   - No tab does two jobs

## LESSON 2: PRE-FLIGHT CHECKLIST

Before replying "done" on ANY deliverable, run this:

```
PRE-FLIGHT:
  1. Did I open the file and LOOK at it?
  2. Is the client/brand name correct?
  3. Are all cells populated (no blank rows mid-data)?
  4. Do dropdowns work when I click them?
  5. Are column widths reasonable (no cut-off text)?
  6. Is the font consistent across ALL tabs?
  7. Did I remove gridlines from presentation tabs?
  8. Would I send this to a paying client?
```

If any answer is NO → fix it, then restart the checklist from #1.

## LESSON 3: WHEN YOU GET STUCK

DON'T sit silent for 3 days. DON'T guess and ship garbage.

1. **Stuck on formatting?** → Drop a reply: "Structure done, need UI guidance on X"
2. **Not sure which brand?** → Ask DEV. Don't guess Crybex vs Foxsy.
3. **Token/auth broke?** → Say so immediately. Don't go dark.
4. **Interrupted mid-batch?** → Finish before replying, or say "X tabs done, Y remaining"
