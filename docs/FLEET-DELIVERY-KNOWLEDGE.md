# Fleet delivery and self-optimizing knowledge

Jericho projects its authoritative lifecycle into a five-stage operator model:

`Intake → Interpret → Approve → Execute → Learn`

The projection does not replace Core's eight persisted stages. Paperclip is a
reconciled execution queue, Obsidian is the complete private human-readable
memory surface, and Notion receives only an approved field-allowlisted
projection. A queue status or wiki write never proves mission completion.

Verified missions produce content-addressed knowledge packages. Obsidian and
Notion writes are destination-scoped projections with receipts bound to the
package hash. Retrieval remains collection-explicit across the private vault,
Core evidence, and shared Notion knowledge.

Candidate retrieval indexes are built beside the active index. Promotion is
allowed only after a fixed benchmark improves quality without regressing
freshness, latency, evidence coverage, duplication, or contradiction rate.
Routing, source knowledge, consolidation, redaction, and benchmark changes
remain review-gated.
